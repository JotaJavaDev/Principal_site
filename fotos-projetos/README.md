# Fotos dos projetos

Coloque as imagens de cada projeto na pasta correspondente:

- `orderly-api/` — screenshots da API Orderly
- `pulse-dashboard/` — screenshots do dashboard Pulse
- `ship-better/` — screenshots da landing page Ship better

Sugestao de nomes:

- `capa.webp` para a imagem principal
- `desktop.webp` para a tela desktop
- `mobile.webp` para a tela mobile
- `detalhe-01.webp` para imagens adicionais

Formatos recomendados: `.webp`, `.jpg` ou `.png`.
